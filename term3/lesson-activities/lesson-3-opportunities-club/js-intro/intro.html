THE ROUTE · 5 IDEAS

Five ideas.
Five small wins.

  • Variables & data typesLabel a value and know what kind of thing it is.
  • Building sentencesDrop variables into a message with template literals.
  • Making a decisionif / else — choosing what happens next.
  • FunctionsA reusable recipe: an input in, a result out.
  • Arrays & loopsA list, and one instruction that repeats for every item.

Each idea gets a GUIDE slide, then an EXERCISE slide. Try the exercise before moving on.

02

GUIDE 1 · 5 MIN

Label a value.
Know its type.

let name = "Amara";
let age = 16;
let isPrefect = true;

console.log(typeof name);       // "string"
console.log(typeof age);        // "number"
console.log(typeof isPrefect);  // "boolean"

let creates a labelled box for a value. A string is text in quotes; a number has none; a boolean is true or false.

Run typeof on all three. Do the results match what you expected?

04

GUIDE 2 · 5 MIN

Drop values
into a sentence.

let school = "Alliance Girls High School";

console.log(`Hello, ${name}!`);
console.log(`${name} studies at ${school}.`);
console.log(`Next year is ${2026 + 1}.`);

Backticks make a template literal. Anything inside ${ } is calculated and dropped in — even maths.

06

GUIDE 3 · 5 MIN

If this is true,
do that.

let ticketsLeft = 3;

if (ticketsLeft > 0) {
  console.log("Tickets available!");
} else {
  console.log("Sold out.");
}

Change ticketsLeft to 0 and predict the output before you run it. === means "exactly equal to" — three signs, not two.

08

GUIDE 4 · 6 MIN

A function
is a recipe.

function greet(studentName) {
  return `Welcome, ${studentName}!`;
}

console.log(greet("Amara"));
console.log(greet("Zawadi"));

studentName is the parameter — what the recipe needs. return is what it hands back. Each call can use a different value.

10

GUIDE 5 · 6 MIN

One instruction.
Every item.

const clubs = ["Coding club", "Debate team", "Science fair"];

console.log(clubs.length);   // 3
console.log(clubs[0]);       // "Coding club"

for (const club of clubs) {
  console.log(club);
}

An array is a list in order — counting starts at 0. for...of visits every item and runs the same code for each.
